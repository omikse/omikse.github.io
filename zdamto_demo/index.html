demo logowania i historii podejść

Zaloguj się kontem Google

Demo pokazuje pełną ścieżkę: logowanie Google → zapis profilu w bazie → rozwiązanie krótkiego testu → zapis odpowiedzi → historia podejść. Twoje dane widzisz tylko Ty.

Co dokładnie trafia do bazy

users/{uid}
  ├─ displayName, email, photoURL
  ├─ createdAt, lastLoginAt, loginCount
  └─ attempts/{attemptId}          ← historia podejść
       ├─ examId, examTitle
       ├─ answers: { "1": …, "2": …, "3": … }
       └─ score, maxScore, finishedAt

To uproszczona wersja docelowego modelu — jeden dokument na podejście, odpowiedzi kluczowane numerem zadania, dokładnie jak w prawdziwym arkuszu.
